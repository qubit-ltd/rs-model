# Java Public API Coverage

This audit compares the public Java types in `java-common/common-model` and
`java-common/common-mixin` with the public Rust API generated by this crate and
its `qubit-mixin` dependency.

## Coverage result

The Java source contains 360 public top-level types: 324 in `common-model` and
36 in `common-mixin`. All 360 have a public Rust counterpart. The only public
nested Java type is `SettingXmlAdapter.Adapted`; its Rust counterpart is
`qubit_model::system::SettingXmlAdapted`.

The deterministic package mappings are:

- `ltd.qubit.model.<package>.<Type>` maps to
  `qubit_model::<package>::<Type>`.
- Root types such as `Entity`, `Field`, `Module`, and `Operation` map directly
  to `qubit_model::<Type>`.
- The source-package compatibility exports for `contact::AddressBuilder`,
  `commons::{Dict, FullDict}`, and the `system` setting and verification types
  preserve the Java package paths even though their Rust implementations live
  in shared implementation modules.
- The 34 ordinary `ltd.qubit.commons.mixin` and `ltd.qubit.commons.util`
  declarations map by exact type name to `qubit_mixin::<Type>`.
- `BeanValidationFailedException` maps to the value-safe
  `qubit_mixin::MixinError::Validation` error boundary.
- The static `NormalizeImpl` utility maps to the Rust-idiomatic
  `qubit_mixin::normalize` function and `Normalizable` implementations.

The non-domain helper types are intentionally public behavior adapters rather
than `Model` values. This includes codecs, JSON serializers and deserializers,
XML adapters, the phone type register, and `SettingRandomizer`. The public XML
transfer value `SettingXmlAdapted` is a domain value and implements both
`Model` and `Redact`.

## Verification

The top-level inventory was produced with:

```sh
rg -l '^public .*\b(class|interface|enum|record)\b' \
  java-common/common-model/src/main/java \
  java-common/common-mixin/src/main/java
```

The result is 324 `common-model` files and 36 `common-mixin` files. Nested
declarations were checked independently with:

```sh
rg '^  public (static )?(class|interface|enum|record) ' \
  java-common/common-model/src/main/java \
  java-common/common-mixin/src/main/java
```

That command reports only `SettingXmlAdapter.Adapted`. Exact source-package
compatibility and the two semantic `common-mixin` mappings are compiled by
`tests/java_api_coverage_tests.rs`; adapter behavior is exercised by
`tests/codec_adapter_tests.rs` and `tests/setting_adapter_tests.rs`.
